# Admin 管理后台需求

> 状态：第一期已确认 · 最后更新 2026-09-28

## 定位

给管理员使用的后台，负责内容、读者和 AI 的全部管理工作。

- 视觉上走简洁的工具风格，直接使用项目现有的 shadcn/ui 组件。
- 界面语言：中文。

## 管理员账户

- 系统中**只有一个管理员账户**。
- 账号和密码在**部署时通过服务器配置（环境变量）设置**，不提供网页上的初始化或注册入口。

## 第一期

### 邀请码

- 管理员生成邀请码，分发给读者。
- **一码一人**：邀请码被成功注册一次后即失效。
- **有效期**：可设置，默认 7 天，过期失效。
- **作废**：管理员可手动作废未使用的邀请码。
- 管理员可查看邀请码列表及状态（未使用 / 已使用 / 已过期 / 已作废），以及已使用的邀请码对应哪个读者。

### 读者管理

- 查看读者列表。
- **禁用 / 启用**读者：被禁用的读者无法登录。
- **重置读者密码**（读者不能自助找回密码）。

### 上传

- 支持上传 `.pdf` 格式的绘本，其他格式暂不支持。
- **单个文件上限 200MB。**
- 按"PDF 每一页 = 一个独立画面"处理，不做跨页拆分。
- **自动裁白边**：拆页时按整本书所有页面内容的并集，统一裁掉四周空白（某一边空白不足 1% 不裁），全书页面尺寸保持一致。第一期不提供手动调整。
- 支持横版和竖版的 PDF。
- PDF 处理完成后，绘本默认为**已上架**状态，读者即可阅读。

### 绘本信息

| 字段 | 默认值 | 管理员可修改 |
| --- | --- | --- |
| 书名 | 取 PDF 文件名 | 是 |
| 封面 | 取 PDF 第一页 | 是 |
| 语言 | 无，需管理员选择（中文 / 英文） | 是 |
| 版式 | 自动识别横版 / 竖版 | 是 |
| 对开配对 | 自动检测（比较相邻两页接缝处的画面是否连续） | 是：自动 / 从第 2 页开始配对（2+3、4+5…）/ 从第 3 页开始配对（3+4、5+6…） |

- **对开配对**只影响竖版书在平板横屏时的对开显示，用于让跨页大图的左右两半拼在一起。检测不出时按"从第 2 页开始配对"（封面单独一页，之后 2+3、4+5…）。

### 书架管理

- 查看所有绘本（含已下架）；列表分页显示，每页 10 本。
- 编辑绘本信息（见上表）。
- **上架 / 下架**：下架后读者看不到，数据保留，可重新上架。**下架需要二次确认**；重新上架不影响读者，直接生效。
- **删除**：需要二次确认，删除后不可恢复。已上架的绘本在确认框中额外提示"读者将无法再阅读"。
- 下架 / 上架、删除在绘本列表的每一行和绘本详情页都可以操作。

## 后续（AI 阶段）

### AI 配置

- 文字提取（OCR）、TTS、视频生成**分别配置**模型和 API Key。
- 所有 AI 成本由管理员承担。
- API Key 只保存在服务端，不下发到阅读端。

### 每页朗读台词

- 每一页有一段**朗读台词**，即 TTS 要读的内容。
- 默认由 OCR 从页面中识别提取，**管理员可以修改**。
- 台词可以为空（无字页），该页不生成朗读音频。

### AI 生成流程

由管理员在后台触发。**一本书生成一次，结果保存下来，所有读者共用。**

```
第一步：识别台词
  OCR 提取每页文字 → 生成台词草稿
  视频生成可同时开始（视频只依赖页面图片，不依赖台词）
        ↓
管理员校对：逐页对照页面图片，修改台词
        ↓
第二步：生成朗读
  按确认后的台词生成 TTS 音频
        ↓
管理员确认 → 标记为 Dance Ready!
```

- **先校对、后朗读**：避免为识别错误的文字生成音频。
- **按页增量重做**：Dance Ready 之后修改某页台词，只重新生成该页音频，不重跑整本书。
- **单页重新生成**：管理员对某页的音频或动画不满意，可以单独重新生成该页。
- **Dance Ready! 由管理员手动确认**，而不是生成完自动切换。
