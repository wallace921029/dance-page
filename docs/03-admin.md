# Admin 管理后台需求

> 需求已确认并已实现 · 最后更新 2026-09-29

## 定位

给管理员使用的后台，负责内容、读者和 AI 的全部管理工作。

- 视觉上走简洁的工具风格，直接使用项目现有的 shadcn/ui 组件（读者端的手绘风格不用在这里）。
- 界面语言：中文。

## 管理员与小小管理员

- 系统中**只有一个管理员账户**。账号和密码在**部署时通过服务器配置（环境变量）设置**，不提供网页上的初始化或注册入口。
- **小小管理员**（D109）：管理员可以在"用户管理 → 读者"里把信任的读者设为小小管理员（也可以随时取消，需要二次确认，立即生效，不需要对方重新登录）。只有管理员能授予或取消；小小管理员不能给别人授权，也不能管理读者。
- 小小管理员仍是读者：可以用书架阅读，也可以预览下架的绘本；登录后先到书架，从头像弹窗里进入管理后台。

| 模块 | 管理员 | 小小管理员 |
| --- | --- | --- |
| **绘本**：上传、编辑、上下架、删除，绘本详情页里的 AI 工作台（含会产生费用的生成） | ✅ | ✅ |
| **用户管理**：邀请码、读者（含授予小小管理员） | ✅ | ❌ 导航里看不到，直接输入地址会被跳回"绘本"，服务端返回 403 |
| **AI 配置**：服务商、模型、视频默认参数 | ✅ | ❌ 同上 |

## 导航与顶栏

- **品牌区**：一个夜幕色的小胶囊——网站 logo（萤火虫照亮打开的书）+ "萤火"字标（与读者首页同款：站酷小薇、舞台金）+ 右下角很小很淡的 "ADMIN"（D106）。整个胶囊是回到"绘本"页的链接。
- **导航**：管理员是"绘本 | 用户管理 | AI 配置"；小小管理员只有"绘本"。
- **右侧**：一个书架图标（"打开读者首页"，回到读者的书架）和头像下拉菜单（用户名——小小管理员会在旁边标注身份——和退出登录）。
- 手机宽度下顶栏放不下会横向滚动（已知问题，管理后台主要在电脑上用，见 [04 路线图](./04-roadmap.md#可以以后再做)）。

## 用户管理

仅管理员。导航里的"用户管理"是一个模块，里面用标签切换"邀请码"和"读者"两个子模块（对应地址 `/admin/users/invites`、`/admin/users/readers`，默认打开邀请码；旧地址 `/admin/invites`、`/admin/readers` 会跳转过来，D107）。

### 邀请码

- 管理员生成邀请码，分发给读者；生成后注册链接自动复制，也可以对每个未使用的邀请码点"复制注册链接"。
- **一码一人**：邀请码被成功注册一次后即失效。
- **有效期**：可设置，默认 7 天，过期失效。
- **作废**：管理员可手动作废未使用的邀请码。
- **删除**（D108）：没被用过的邀请码（未使用、已过期、已作废）都可以删除，需要二次确认；删除未使用的邀请码后，已经发出去的注册链接立即失效。已使用的邀请码不能删，要留着记录读者是用哪个码注册的。
- 邀请码列表显示状态（未使用 / 已使用 / 已过期 / 已作废），以及已使用的邀请码对应哪个读者。

### 读者

- 查看读者列表：用户名、**角色**（读者 / 小小管理员）、状态、注册时间、最近使用。
- **设为 / 取消小小管理员**（D109）：二次确认，确认框里写明小小管理员能做什么、看不到什么。
- **禁用 / 启用**读者：被禁用的读者立即退出登录、无法再登录。
- **重置读者密码**（读者不能自助找回密码）。
- 管理员账号本身不出现在这个列表里。

## 绘本管理

### 上传

- 支持上传 `.pdf` 格式的绘本，其他格式暂不支持。
- **单个文件上限 200MB。**
- 按"PDF 每一页 = 一个独立画面"处理，不做跨页拆分。
- **自动裁白边**：拆页时按整本书所有页面内容的并集，统一裁掉四周空白（某一边空白不足 1% 不裁），全书页面尺寸保持一致。不提供手动调整。
- 支持横版和竖版的 PDF。
- PDF 处理完成后，绘本默认为**已上架**状态，读者即可阅读；处理中显示进度，失败时给出原因。

### 绘本信息

| 字段 | 默认值 | 管理员可修改 |
| --- | --- | --- |
| 书名 | 取 PDF 文件名 | 是 |
| 封面 | 取 PDF 第一页 | 是（从本书的页面中选一页） |
| 语言 | 无，需管理员选择（中文 / 英文） | 是 |
| 版式 | 自动识别横版 / 竖版 | 是 |
| 对开配对 | 自动检测（比较相邻两页接缝处的画面是否连续） | 是：自动 / 从第 2 页开始配对（2+3、4+5…）/ 从第 3 页开始配对（3+4、5+6…） |

- **对开配对**只影响竖版书在平板横屏时的对开显示，用于让跨页大图的左右两半拼在一起。检测不出时按"从第 2 页开始配对"（封面单独一页，之后 2+3、4+5…）。

### 书架管理

- 查看所有绘本（含已下架）；列表分页显示，每页 10 本。
- 编辑绘本信息（见上表）。
- **上架 / 下架**：下架后读者看不到，数据保留，可重新上架。**下架需要二次确认**；重新上架不影响读者，直接生效。
- **删除**：需要二次确认，删除后不可恢复。已上架的绘本在确认框中额外提示"读者将无法再阅读"。
- 下架 / 上架、删除在绘本列表的每一行和绘本详情页都可以操作。

## AI 配置

仅管理员。

- 故事与台词识别（多模态大模型）、朗读（TTS）、动画视频**分别配置**服务商、模型名和 Base URL；使用国内服务商（阿里云百炼、火山引擎，D66）。
- **两家都接入**，三种能力各自可选服务商，管理员可随时切换（D76）。
- 模型名可以手动输入，也可以从服务商的模型列表里选；每种能力有"测试连接"（D84）。
- 动画视频的**时长、清晰度可配置**，可选范围以所选视频模型支持的为准（D77）；默认清晰度取模型支持的最低一档，通常是 480p，省钱（D102）。
- 以上都是全局默认；生成动画（封面动画和每个开页的动画）时，可以在"生成选项"里临时选别的时长和清晰度，只对这一次生效（D79、D101）。
- 切换服务商不影响已生成的朗读和动画；角色音色与服务商绑定，切换朗读服务商后要按同一段音色提示词在新服务商上重新设计音色（D78）。
- 所有 AI 成本由管理员承担。
- API Key 写在服务器的 `.env` 文件里，修改后重启服务生效；后台只显示是否已设置和末 4 位（D82）。Key 不下发到阅读端。

## AI 工作台

管理员和小小管理员都可以使用（在绘本详情页里）。

### 在哪里操作（D71）

所有 AI 操作都在**绘本详情页的"页面"模块**里完成。该模块已按平板横屏时的对开方式把页面分成一个个**开页**（封面单独一个，之后左右两页一组），AI 的配置和生成挂在每个开页上。

```
页面（30 页）                                    [分析整本故事] [全部生成]
┌ 故事与角色 ───────────────────────────────────────────┐
│ 故事：波西和皮普在森林里遇到了……                           │
│ 角色：旁白 ─ 温柔的女声，讲故事的语气               [试听]  │
│       波西 ─ 5 岁小女孩，声音软糯                  [试听]  │
│       大怪兽 ─ 低沉但不吓人，有点憨                 [试听]  │
└─────────────────────────────────────────────────────┘
开页 3（第 4–5 页）          ○ 分别生成   ● 合并生成
  [第 4 页图][第 5 页图]
  台词：旁白：有一天……  波西："你是谁呀？"
  动作：大怪兽眨眨眼、尾巴左右摆动，树叶轻轻晃动
  朗读 [生成] ▶ 试听          动画 [生成] ▶ 预览
```

模块从上到下：流程说明 → 故事与角色 → 封面动画 → 生成进度（朗读、动画各一行）→ 开页列表。

### 第一步：分析整本故事（D71）

多模态大模型通读整本书的页面图片，给出：

- **故事**：整本书讲了什么；
- **角色**：旁白和故事里的角色；
- **每个角色的音色提示词**：如"波西：5 岁左右的小女孩，声音软糯、语速偏慢"。

之后每个开页的台词、说话人和动作描述都参考整本故事生成，保证角色名前后一致、语气贴合剧情。重新分析会覆盖所有草稿，需要二次确认。

### 第二步：逐个开页生成朗读和动画（D71）

- 管理员为每个开页选择：
  - **分别生成**：左页、右页各自一段朗读、各自一段动画；
  - **合并生成**：两页其实是同一个场景，合起来生成一段朗读、一段动画（视频基于左右拼成的整张图）。
- 横版书每页单独一个单元，只有"分别生成"（D75）。
- 每个单元（单页或合并的开页）有：
  - **台词**：一行一行标明说话人（旁白、波西……）。书上印的原文逐字保留，大模型再结合画面每页补充 2–3 句简短的描写、拟声词或对白，让朗读更生动；没有文字的页面配 1–2 句旁白；补充的行标"补充"（D93）。版权页、空白页可以为空，为空时不生成朗读；
  - **动作描述**：让画面里的关键人物或物品做的循环动作，像《预言家日报》上会动的照片：主体明显地动，背景轻轻地动；只写画面里看得见的、能来回往复的动作，如"大怪兽眨眨眼、尾巴左右摆动，树叶轻轻晃动"，作为视频生成的提示词（D64、D99）。没有角色或物品可动的页面（书名页、版权页、纯文字页）留空，留空的单元不生成动画；文字永远不动（D98）；
  - 朗读、动画各自的"生成"按钮和试听 / 预览。封面动画和每个动画单元的生成按钮旁都有"生成选项"小弹窗，可以临时选时长和清晰度（可选项跟随当前视频模型），只对这一次生效（D79、D101）。
- 第 1 页是封面时，这一页的动画由"封面动画"负责，不单独生成开页动画（D98）。
- 进度卡片里朗读、动画各一行：生成进度、"全部生成"（按每个开页已设好的方式，把未生成、失败或草稿已改的单元一次放进队列）、确认 Voice Ready / Dance Ready!；每个开页也有"生成本开页朗读""生成本开页动画"按钮，一次生成这个开页的所有单元。
- 动画每段约需 1–3 分钟，服务商那边最多同时生成 3 段，生成期间可以做别的事。
- 每个开页有"朗读""动画"两个开关（默认打开）。关闭后这个开页在一键生成时被跳过，阅读时也不朗读 / 不播放动画；已生成的内容保留，重新打开即恢复（D95）。做不做朗读、做不做动画都由管理员按开页决定。

### 封面动画（D96）

- 绘本详情页的"封面动画"卡片：预览（可放大）、动作描述（"分析整本故事"时自动填草稿，可改；留空时生成前由 AI 看封面写）、生成 / 重新生成（旁边有"生成选项"）、"在书架和阅读页封面上播放"开关。
- 以当前封面为首帧生成一段视频，再正放、倒放连成来回循环（首尾都是封面原图，循环无接缝，D99）；约需 1–3 分钟，生成期间可以做别的事。
- 改了动作描述显示"需要重新生成"，读者仍看到原来的动画；换了封面后旧动画对不上，读者不再看到，需重新生成后再启用。临时换清晰度不算"需要重新生成"。

### 多角色朗读与音色（D72）

- 朗读按角色分音色：台词的每一行用该行说话人对应的音色合成。
- 音色由角色的音色提示词决定：服务商支持"用文字描述设计音色"时，直接按提示词生成专属音色；不支持时从现成音色中选最接近的。管理员可以试听并更换。
- 音色在 AI 处理阶段确定，读者阅读时不能选择（D63）。
- 对开且"分别生成"时，朗读顺序按书配置，默认先左后右（D62、D69）；"合并生成"本身就是一段完整的朗读。

### 规则

- **大模型给的都是草稿**：故事、角色、音色提示词、台词、说话人、动作描述，管理员都可以修改，改完再生成（D73）。
- **先校对、后生成**：避免为识别错误的文字生成音频。
- **按单元增量重做**：修改某个单元的台词，只重新生成该单元的音频，不重跑整本书；朗读或动画不满意也可以单独重新生成，重新生成失败时保留上一版。
- **失败不自动重试**：生成失败即标记失败，由管理员查看后重试（D65）。
- **不做费用预估**：生成前不显示预估费用，"全部生成"也不需要二次确认（D65）。
- **两个状态相互独立，都由管理员手动确认**（D61、D67）：朗读满意后确认 → Voice Ready；动画满意后确认 → Dance Ready!。一本书可以只有朗读，也可以只有动画。至少生成了一个单元才能确认，确认前提示还没生成、需要重新生成的单元数（D94、D98）。

## 界面动效

- 切换页面时内容淡入；表格行、卡片等模块在出现时依次淡入上浮，页面缩略图依次出现（D86）。用户管理里切换标签时只换标签下面的内容。
- 系统开启"减少动态效果"时只保留淡入。
