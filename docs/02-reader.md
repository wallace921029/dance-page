# 阅读端需求

> 状态：第一期已确认 · 最后更新 2026-09-28

## 定位

给孩子使用的阅读界面，**只读**：浏览书架、打开绘本、翻页阅读。不提供上传、删除、编辑等任何管理功能。界面尽量简洁，避免孩子误操作。

## 设备与浏览器

- 主要设备：**平板电脑**（触屏操作）。
- **优先保证 iPad Safari**，兼顾 Android 平板 Chrome。
- 支持"添加到主屏幕"：从主屏幕打开时像 App 一样全屏显示，没有浏览器地址栏；夜幕背景一直铺到状态栏下面（D59）。第一次从主屏幕打开需要重新登录一次（iOS 上主屏幕 App 与 Safari 不共享登录状态）。
- 界面语言：**中文**（绘本内容可以是中文或英文，与界面语言无关）。

## 视觉风格：小剧场

总原则：温暖、柔和，但**不抢绘本的戏**，界面元素少，让绘本画面做主角。

阅读页（以及登录、注册页）使用 **B 小剧场**，示意图见 [风格对比页](https://claude.ai/artifact/3TwChZ4w49eXKvKkSMSW1z)（方案 B）。书架页提供四套可切换的主题，见下方"书架主题"。

**概念**：书架是一座深色的小舞台，每本书站在一束光里；打开绘本就像开演，四周暗下去，书页被聚光灯照亮。与"Dance Ready!"以及 AI 阶段"页面动起来"的舞台隐喻一致；夜幕中的一束暖光也呼应产品名"萤火"。

| 元素 | 设计 |
| --- | --- |
| 书架 | 见下方"书架主题"（默认萤火夜空） |
| "Dance Ready!" 标识 | 封面底部一块会发光的剧场招牌（虚线灯泡边框，缓慢呼吸发光） |
| 阅读页背景 | 中心亮、四周暗的舞台光，书页周围有暖色光晕 |
| 阅读页按钮 | 半透明圆形按钮，暖金色图标；页码用暖金色 |

**配色**

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 夜幕 | `#141833` | 主背景 |
| 台面 | `#2B3062` | 阅读页中心的舞台光 |
| 幕布 | `#8A2633` | 两侧幕布 |
| 聚光 | `#FFD66B` | 高亮、"Dance Ready!" 招牌 |
| 舞台光 | `#F5D98B` | 标题、图标、页码 |

**字体**：标题和页码用 ZCOOL XiaoWei（站酷小薇），"Dance Ready!" 招牌用 ZCOOL QingKe HuangYou（站酷庆科黄油体），正文用 Noto Sans SC。

**注意事项**

- 深色界面上的文字和按钮需保证足够对比度。
- 发光动画需尊重系统的"减少动态效果"设置。
- 白天明亮环境下若整体偏暗，上线后再根据实际体验调整。


### 书架主题

书架页提供四套主题（D47），在书架右上角头像菜单的"书架主题"中切换；选择保存在当前设备上，每台平板可以各用各的，默认"萤火夜空"。方案对比见 [书架主题方案](https://claude.ai/artifact/Ts4YYzejRL5ZTtcBUmFqCo)（本地副本 [design/shelf-style-options.html](./design/shelf-style-options.html)）。

| 主题 | 背景与装饰 | 封面处理 |
| --- | --- | --- |
| 萤火夜空（默认） | 夜空渐变、星星、弯月、圆润的小山丘、几只缓慢飘动的萤火虫 | 暖白细描边 + 光晕，下方暖色光斑 |
| 晴天书架 | 浅天蓝到浅薄荷的天空、白云、小太阳；绘本立在木书架上 | 淡描边 + 投影 |
| 黄昏萤火 | 暖橙到靛蓝的黄昏天空，底部小屋和小树剪影，草地上的萤火虫 | 暖白描边 + 投影 |
| 纸剪花园 | 灰绿色调，三层纸剪山丘和纸云 | 淡描边 + 投影 |

- 所有主题都要保证彩色、浅色（大面积白色）、深色三类封面清晰可见。
- 萤火虫动画在系统开启"减少动态效果"时停止。
- 阅读页不随书架主题变化，始终是小剧场的深色舞台。

### 书本动效

书架上的书有三种动效（D52），平时书是静止的，封面始终清晰。动效演示见 [书架动效方案](https://claude.ai/artifact/7dxSsuxAx7DXnBbT4weF33)。

| 动效 | 何时出现 | 说明 |
| --- | --- | --- |
| 依次跳上书架 | 打开应用后第一次进入书架 | 当前页的书一本接一本从下方弹上来落位；从阅读页返回、翻页时不再播放 |
| 点按回弹 + 翻开进入阅读 | 点一本书 | 书被轻轻压扁后弹起、迸出几颗萤火光点；封面飞到阅读页上封面的位置，四周变暗成阅读页，再用翻页效果自动翻开封面 |
| 萤火虫落在书上 | 闲置时每 12–20 秒一次 | 一只萤火虫飞来停在屏幕上某本书的右上角，这本书微微发亮后飞走；只在萤火夜空、黄昏萤火两个主题出现 |

- 书架右上角菜单的"书本动效"可以关闭全部动效，选择保存在当前设备上；系统开启"减少动态效果"时自动全部关闭。
- 不做持续的摇摆动效，避免分散注意力。

## 账户

- **注册**：填写邀请码 + 用户名 + 密码，不需要邮箱和手机号。
  - 用户名 2–20 位，可用中文、字母、数字、下划线，不区分大小写（`Tom` 与 `tom` 视为同一个）。
  - 密码至少 6 位，不要求复杂度（使用者是家庭成员，优先好记）。
- **登录**：必须登录后才能访问书架和绘本。
- **登录保持 30 天**，期间使用会自动续期。平板上登录一次后基本不需要再输入密码。
- **忘记密码**：联系管理员在后台重置，不提供自助找回。
- 被管理员禁用的读者无法登录。

## 书架

- **简单的封面网格**，每页最多展示 8 本"已上架"的绘本；上一页按钮、页码、下一页按钮固定在视口底部（避开设备安全区），不挤占绘本布局，翻页时按方向滑动（系统开启减少动态效果时不播放）。点击封面打开阅读，返回书架时保留原页码。
- **翻页按钮**为手绘涂鸦风格（D57），与收藏爱心同一套画法：暖黄色手画圆圈 + 墨线箭头 + 白色贴纸边；翻不了时变淡变灰；点击时箭头朝翻页方向轻推一下。页码下方有一道手画波浪线，颜色随主题。
- **一屏显示、不出现滚动条**（D53）：书架页固定为一屏高。每页 8 本的排法随屏幕方向变化：横屏 4 列 × 2 行（两排按封面高度靠拢，整体居中；空间不足时缩小书格），平板竖屏 3 列 × 3 行，手机竖屏 2 列 × 4 行；封面在格子内按比例缩放、底部对齐。书格底部与固定的翻页按钮之间保留空间。
- 所有读者看到的书架相同。
- 按**上传时间倒序**排列，新书在最前。
- **搜索**（D54）：品牌名右侧的放大镜按钮，点击后搜索框弹性展开并自动聚焦；按书名即时筛选（忽略大小写和空格），搜不到时提示并可一键清除；关闭按钮或 Esc 清空并收起。搜索词保存在地址里，打开绘本再返回时保留。
- **收藏**（D55）：每本书封面左上角有一个小爱心，点一下收藏 / 取消收藏，不会打开绘本。收藏按账号保存，换设备登录后仍在。
  - 爱心为手绘涂鸦风格（D56）：像歪贴在封面角上的贴纸（白边 + 两遍墨线），已收藏为粉色蜡笔填充，未收藏为奶油色；在深色、浅色、彩色封面上都清楚。
  - 收藏时的反馈：墨线像现场画出来一样描一遍，爱心弹起并晃一下，周围飘出几颗手绘小爱心、小星星后淡出；取消收藏时轻轻缩一下。受"书本动效"开关和系统"减少动态效果"控制。
- **我的收藏**（D55、D58）：头像左侧的手绘爱心按钮进入 `/favorites`（在收藏页时显示为选中状态，再点一下回到全部绘本），展示方式与首页相同（主题、分页、动效、搜索都一致），最近收藏的在前；在这里取消收藏，绘本会立即从列表移除。
- 第一期不做分类、"继续阅读"。

## 阅读

### 翻页

- **仿真翻页**：像翻真书一样卷页翻过去。
- **不记录阅读进度**：每次打开绘本都从封面开始。

### 横竖版排版

横版、竖版 PDF 都要正确显示，不能出现画面被裁切或严重变形。排版规则如下（先按此实现，看实际效果再调整）：

| 绘本版式 | 平板横屏 | 平板竖屏 |
| --- | --- | --- |
| **竖版书** | 对开双页（像摊开的真书），封面单独一页 | 单页 |
| **横版书** | 单页 | 单页，上下留白 |

- 版式按整本书统一判断，不逐页切换。
- **跨页大图**：有些绘本把一幅跨页大图拆成左右两页。对开显示时按绘本的"对开配对"设置（见 [Admin - 绘本信息](./03-admin.md#绘本信息)）配对，保证左右两半拼在一起；需要时在封面后补一张空白页对齐。单页显示时两半分别显示，不做特殊处理。

### 阅读页操作

第一期只提供以下操作，保持界面简洁：

- **返回书架**
- **页码显示**（如 `3 / 24`）
- **全屏**
- **读完提示**：翻到最后一页时，页码位置换成提示"故事讲完啦！"和"合上书本"按钮；点击后以一次翻页动画合上书，回到封面。不自动合上，孩子可以继续看最后一页或往回翻。

第一期不提供缩放。

## 后续（AI 阶段）

- 朗读、动画都播放管理员预先生成好的内容，阅读端不触发 AI 生成。

**朗读**（Voice Ready 的绘本，D62、D63）

- 每页有朗读按钮，点击播放本页朗读。
- 阅读页上有"自动朗读"开关，打开后翻到新页自动朗读；开关状态记在当前设备上。读完不自动翻页，由孩子自己翻（D68）。
- 对开时，"分别生成"的两页按管理员为这本书设置的顺序连续朗读，默认先左后右（D69）。
- 竖屏单页显示"合并生成"的开页时，在两页中任一页点朗读都播放整段；自动朗读只在翻到前一页时读一次（D74）。
- 不做文字高亮。
- 多角色朗读：旁白和各角色用不同音色（D72）。音色由管理员在 AI 处理时确定，读者不能选择。
- 没有朗读的页面（无字页、管理员没有生成）不显示朗读按钮。
- 书架上，有朗读的书在书名前显示一个音乐符号（D70）。

**封面动画**（D96）

- 像《哈利·波特》里魔法报纸上会动的照片：封面里的角色轻轻眨眼、呼吸，头发衣角微微飘动，幅度很小，其余画面不变，循环播放。
- 书架上一直轻轻循环，只播放屏幕里看得见的；系统开启"减少动态效果"或关闭书本动效时不播放。
- 阅读页：封面翻开前也在动，开始翻页时立即停住、露出静态封面（封面是第 1 页时）。
- 由管理员生成、预览、启用后读者才看得到；与 Dance Ready! 相互独立，封面动了也不显示"Dance Ready!"招牌。

**动画**（Dance Ready! 的绘本，D64）

- 不是动画片：画面里的关键人物或物品做一个简单、短暂的循环动作（如兔子踢球时腿慢慢摆动），背景和其余画面保持不动。
- "合并生成"的开页作为一整张画面动起来，左右两页衔接一致；竖屏单页时，左页播放视频的左半边、右页播放右半边（D74）。
- 书架上，有动画的书在封面底部显示"Dance Ready!"剧场招牌。
- 朗读与动画相互独立（D67），一本书可以只有其中一种。
