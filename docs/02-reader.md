# 阅读端需求

> 状态：第一期已确认 · 最后更新 2026-09-28

## 定位

给孩子使用的阅读界面，**只读**：浏览书架、打开绘本、翻页阅读。不提供上传、删除、编辑等任何管理功能。界面尽量简洁，避免孩子误操作。

## 设备与浏览器

- 主要设备：**平板电脑**（触屏操作）。
- **优先保证 iPad Safari**，兼顾 Android 平板 Chrome。
- 支持"添加到主屏幕"：从主屏幕打开时像 App 一样全屏显示，没有浏览器地址栏。
- 界面语言：**中文**（绘本内容可以是中文或英文，与界面语言无关）。

## 视觉风格：小剧场

总原则：温暖、柔和，但**不抢绘本的戏**，界面元素少，让绘本画面做主角。

阅读页（以及登录、注册页）使用 **B 小剧场**，示意图见 [风格对比页](https://claude.ai/artifact/3TwChZ4w49eXKvKkSMSW1z)（方案 B）。书架页提供四套可切换的主题，见下方"书架主题"。

**概念**：书架是一座深色的小舞台，每本书站在一束光里；打开绘本就像开演，四周暗下去，书页被聚光灯照亮。与"Dance Ready!"以及 AI 阶段"页面动起来"的舞台隐喻一致；夜幕中的一束暖光也呼应产品名"萤火"。

| 元素 | 设计 |
| --- | --- |
| 书架 | 见下方"书架主题"（默认萤火夜空） |
| "Dance Ready!" 标识 | 封面底部一块会发光的剧场招牌（虚线灯泡边框，缓慢呼吸发光） |
| 阅读页背景 | 中心亮、四周暗的舞台光，书页周围有暖色光晕 |
| 阅读页按钮 | 半透明圆形按钮，暖金色图标；页码用暖金色 |

**配色**

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 夜幕 | `#141833` | 主背景 |
| 台面 | `#2B3062` | 阅读页中心的舞台光 |
| 幕布 | `#8A2633` | 两侧幕布 |
| 聚光 | `#FFD66B` | 高亮、"Dance Ready!" 招牌 |
| 舞台光 | `#F5D98B` | 标题、图标、页码 |

**字体**：标题和页码用 ZCOOL XiaoWei（站酷小薇），"Dance Ready!" 招牌用 ZCOOL QingKe HuangYou（站酷庆科黄油体），正文用 Noto Sans SC。

**注意事项**

- 深色界面上的文字和按钮需保证足够对比度。
- 发光动画需尊重系统的"减少动态效果"设置。
- 白天明亮环境下若整体偏暗，上线后再根据实际体验调整。


### 书架主题

书架页提供四套主题（D47），在书架右上角头像菜单的"书架主题"中切换；选择保存在当前设备上，每台平板可以各用各的，默认"萤火夜空"。方案对比见 [书架主题方案](https://claude.ai/artifact/Ts4YYzejRL5ZTtcBUmFqCo)（本地副本 [design/shelf-style-options.html](./design/shelf-style-options.html)）。

| 主题 | 背景与装饰 | 封面处理 |
| --- | --- | --- |
| 萤火夜空（默认） | 夜空渐变、星星、弯月、圆润的小山丘、几只缓慢飘动的萤火虫 | 暖白细描边 + 光晕，下方暖色光斑 |
| 晴天书架 | 浅天蓝到浅薄荷的天空、白云、小太阳；绘本立在木书架上 | 淡描边 + 投影 |
| 黄昏萤火 | 暖橙到靛蓝的黄昏天空，底部小屋和小树剪影，草地上的萤火虫 | 暖白描边 + 投影 |
| 纸剪花园 | 灰绿色调，三层纸剪山丘和纸云 | 淡描边 + 投影 |

- 所有主题都要保证彩色、浅色（大面积白色）、深色三类封面清晰可见。
- 萤火虫动画在系统开启"减少动态效果"时停止。
- 阅读页不随书架主题变化，始终是小剧场的深色舞台。

## 账户

- **注册**：填写邀请码 + 用户名 + 密码，不需要邮箱和手机号。
  - 用户名 2–20 位，可用中文、字母、数字、下划线，不区分大小写（`Tom` 与 `tom` 视为同一个）。
  - 密码至少 6 位，不要求复杂度（使用者是家庭成员，优先好记）。
- **登录**：必须登录后才能访问书架和绘本。
- **登录保持 30 天**，期间使用会自动续期。平板上登录一次后基本不需要再输入密码。
- **忘记密码**：联系管理员在后台重置，不提供自助找回。
- 被管理员禁用的读者无法登录。

## 书架

- **简单的封面网格**，展示所有"已上架"的绘本，点击封面打开阅读。
- 所有读者看到的书架相同。
- 按**上传时间倒序**排列，新书在最前。
- 第一期不做分类、搜索、"继续阅读"。

## 阅读

### 翻页

- **仿真翻页**：像翻真书一样卷页翻过去。
- **不记录阅读进度**：每次打开绘本都从封面开始。

### 横竖版排版

横版、竖版 PDF 都要正确显示，不能出现画面被裁切或严重变形。排版规则如下（先按此实现，看实际效果再调整）：

| 绘本版式 | 平板横屏 | 平板竖屏 |
| --- | --- | --- |
| **竖版书** | 对开双页（像摊开的真书），封面单独一页 | 单页 |
| **横版书** | 单页 | 单页，上下留白 |

- 版式按整本书统一判断，不逐页切换。
- **跨页大图**：有些绘本把一幅跨页大图拆成左右两页。对开显示时按绘本的"对开配对"设置（见 [Admin - 绘本信息](./03-admin.md#绘本信息)）配对，保证左右两半拼在一起；需要时在封面后补一张空白页对齐。单页显示时两半分别显示，不做特殊处理。

### 阅读页操作

第一期只提供以下操作，保持界面简洁：

- **返回书架**
- **页码显示**（如 `3 / 24`）
- **全屏**
- **读完提示**：翻到最后一页时，页码位置换成提示"故事讲完啦！"和"合上书本"按钮；点击后以一次翻页动画合上书，回到封面。不自动合上，孩子可以继续看最后一页或往回翻。

第一期不提供缩放。

## 后续（AI 阶段）

- 对"Dance Ready!"的绘本，读者可以使用朗读和动画。
- 朗读、动画都播放管理员预先生成好的内容，阅读端不触发 AI 生成。
- 无朗读台词的页面（无字页）不播放朗读。
