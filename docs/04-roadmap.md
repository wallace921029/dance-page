## 5. 范围边界（明确不做）

| 不做 | 说明 |
| --- | --- |
| 开放注册 | 只能凭邀请码注册（D13、D21）；不做邮箱 / 手机号、自助找回密码（忘记密码由管理员重置） |
| 按读者分配绘本 | 所有读者共用同一个书架（D25） |
| 阅读进度、"继续阅读" | 每次打开绘本都从封面开始（D18） |
| 书架分类 | 只有按上传时间倒序的一个书架，加搜索和收藏 |
| 阅读页缩放 | 阅读页只提供返回、页码、全屏，以及朗读相关按钮（D28、D94） |
| PDF 以外的上传格式、跨页拆分 | 一页 PDF 就是一个画面（D2、D7） |
| 多语言界面 | 界面只做中文（D35）；绘本内容可以是中文或英文 |
| 离线缓存 | 不引入 Service Worker |
| 文字高亮 | 朗读时不高亮文字（D62） |
| 读者自选音色 | 音色由管理员按书、按角色确定（D63） |
| 生成前的费用预估与确认 | 也不自动重试失败的生成，失败后由管理员处理（D65） |

## 6. 兼容性目标

- 优先保证 **iPad Safari**，兼顾 Android 平板 Chrome；桌面浏览器用于管理后台（D32）。
- 界面语言只做中文。
