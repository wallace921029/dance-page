# 第一期 MVP 范围

> 状态：已确认 · 最后更新 2026-09-28

第一期目标：把"**上传 → 书架 → 翻页阅读**"跑通，并具备在公网上安全使用的账户体系。不包含任何 AI 功能。

- **P0**：第一期必须有，缺了不能上线。
- **P1**：第一期希望有，时间紧可以推迟。

## 账户

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 管理员登录 | 账号密码来自服务器配置 |
| P0 | 读者注册 | 邀请码 + 用户名 + 密码 |
| P0 | 读者登录 / 退出 | 登录保持 30 天，使用时自动续期 |
| P0 | 访问控制 | 未登录不能访问任何页面和绘本资源（含图片）；读者不能访问 Admin |

## Admin 管理后台

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 生成邀请码 | 一码一人，可设有效期（默认 7 天） |
| P0 | 邀请码列表 | 显示状态和对应读者；可作废未使用的邀请码 |
| P0 | 读者列表 | 禁用 / 启用、重置密码 |
| P0 | 上传 PDF | ≤ 200MB；显示上传进度和处理状态；失败时给出原因 |
| P0 | PDF 处理 | 拆分为页面图片、识别横竖版、取第一页为默认封面 |
| P0 | 绘本列表 | 显示全部绘本及上架状态 |
| P0 | 编辑绘本信息 | 书名、语言、版式 |
| P0 | 上架 / 下架 | |
| P0 | 删除绘本 | 二次确认 |
| P0 | 更换封面 | 从本书的页面中选一页作为封面 |
| P1 | 邀请码一键复制 | 复制带邀请码的注册链接，方便发给读者 |

## 阅读端

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 封面网格书架 | 只显示已上架的绘本，按上传时间倒序 |
| P0 | 仿真翻页 | 卷页效果，支持触屏滑动 |
| P0 | 横竖版排版 | 按 [阅读端需求](./02-reader.md#横竖版排版) 中的规则 |
| P0 | 返回书架、页码显示 | |
| P0 | 全屏 | |
| P1 | 页面预加载 | 提前加载后面几页，翻页不等待 |
| P1 | 添加到主屏幕 | 从主屏幕打开时全屏显示，像 App 一样 |
| P1 | 按书名搜索 | 书架标题右侧的搜索（D54，原列为"不做"，用户后续要求加入） |
| P1 | 收藏与"我的收藏" | 封面左上角的爱心、头像菜单中的收藏列表（D55） |

## 兼容性

- 优先保证 iPad Safari，兼顾 Android 平板 Chrome。
- 界面语言只做中文。

## 明确不做（第一期）

- 所有 AI 功能：台词识别、TTS 朗读、页面动画、AI 配置
- 阅读进度记录、"继续阅读"
- 书架分类
- 阅读页缩放
- 按读者分配绘本权限
- 邮箱 / 手机号、自助找回密码
- PDF 以外的上传格式、跨页拆分
